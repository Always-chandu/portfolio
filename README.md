## ⚡ NEO-BRUTALISM UI/UX DESIGN

- **Solid Black Outlines & Borders:** `3px solid #050505`
- **Hard Drop Shadows (No Blur):** `4px 4px 0px #050505`, `6px 6px 0px #050505`, `8px 8px 0px #050505`
- **Tactile Hover Dynamics:** Elements depress on active click (`translate(2px, 2px)`) and lift on hover with offset shadows
- **Playful Elements:** Retro ticker/marquee, angled sticker badges, monospace developer terminal, case file project cards
- **Strict Color Policy:** **100% Free of Purple and Blue**.
